# ADR-0009: opt-in typed planner and canonical fact projections

Status: accepted bounded implementation; owner accepted design PR9 in chat and requested implementation. Prototype/production acceptance remains separate.

Represent up to4 requirements for3 exact entities in immutable QueryPlanV2. Each need carries independent document-kind and representation constraints. Deterministic canonical projections retain subject/header/value spans, parser/projection revisions, units, complete group identity and cardinality. Open lists, malformed counts and incompatible scopes fail closed; table members do not prove an unqualified complete interface set. Explicit interface qualifiers are typed selectors rather than discarded context.

Gate all needs against one captured canonical snapshot and atomic current local_index AND local_generate permissions. Same retrieved manual may expand by one canonical page anchor, within5chunks/8000characters. Backend document/entity-type references are separate from engineering quotations. Fake provider may emit only exact complete canonical quote sets; backend reconstructs citations/references and rechecks policy. V1 remains default; v2 is explicit opt-in with no fallback.

Evaluate calibration separately from a new40case independently authored/reviewed set. The implementer may inspect only blind manifest/hash/counts until clean committed code/config/artifact freeze. A durable exclusive dataset-SHA START precedes parsing and model evaluation; a failure consumes the set and persists an invalid outcome with partial rows. After the first result, no runtime/config tuning on that set. Report requirement correctness separately from conjunctive exact gold-pointer coverage; normalize canonical metadata references equally across v1/v2. Target24/24 positives and16/16 refusal/clarification outcomes, valid complete answers only. A smaller result must remain a quality failure.

No new models/dependencies, real source approvals, cloud provider, deployment or Saturn-Main-Site writes. Existing local E5/mmarco bundles only. Exact quote support and typed binding do not establish general natural-language entailment or engineering advice quality.
