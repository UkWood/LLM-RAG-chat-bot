# ADR-0001: независимые RAG, KB и генеративный провайдер

Дата: 2026-11-03. Статус: proposed, ожидает принятия архитектуры владельцем.

## Контекст

Сайт Astro статический и находится в другом репозитории. Нужен технический консультант с проверяемыми источниками, локальным поиском и будущей сменой Cloud Qwen на local inference. Исходники и произвольные файлы не разрешены для облачной отправки.

## Предлагаемое решение

- FastAPI orchestration, typed domain contracts, provider adapter с OpenAI-compatible реализациями; fake для offline CI.
- Локальные embeddings и reranker; Qdrant dense + BM25 одного snapshot, RRF. Модели выбираются benchmark, provider не управляет индексом.
- Явный реестр допуска exact source revisions, deny-by-default, hash-pinning и revocation; публичность не наследуется вложенными документами.
- Backend владеет citations, privacy и refusal; неподтверждённый результат закрывается.
- Отдельный статический Astro UI и будущий переносимый клиент; сайт не изменяется.

## Альтернативы и последствия

Qdrant dense+sparse — возможная оптимизация после русского retrieval benchmark. Managed RAG и fine-tuning не удовлетворяют требованиям контроля KB/миграции. Большой agent framework добавляет зависимости без необходимого сценария.

Два индекса требуют atomic snapshot pointer и проверки консистентности. Generative provider можно менять конфигурацией; embedding model менять без переиндексации нельзя. Реальный grounding требует оценки поддержки утверждений, проверки ID недостаточно. Буферизация ответа до проверки уменьшает ощущение streaming, но не показывает неподтверждённый текст.

## Принятие

Реализация не начата; показатели качества/CPU и допуск PUBLIC не считаются установленными этим ADR. Детали и проверки — в design document и roadmap.
