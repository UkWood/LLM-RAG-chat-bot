## Назначение пакета

Этот каталог фиксирует единый концепт технического консультанта для конкретного сайта МНПП «Сатурн»: источники знаний, две существующие поисковые подсистемы, границы доступа, архитектуру RAG, этапы реализации и критерии приёмки.

Документы дополняют, но не заменяют существующую память проекта в корне репозитория, docs/PROJECT_STATUS.md, ADR и отчёты этапов.

## Зафиксированные границы

- UkWood/Saturn-Main-Site — **строго read-only**. Никаких изменений файлов, конфигурации, CI, URL, assets, веток, коммитов или истории.
- Вся реализация и проектная документация консультанта ведутся в UkWood/LLM-RAG-chat-bot.
- Существующие пользовательские поиски сайта не заменяются и не переделываются.
- RAG получает собственные индексы и API. Существующие индексы сайта используются как описание поведения и как источник проверяемых метаданных, но не как готовая RAG-база.
- Первоначальный корпус — ориентировочно 10 разрешённых источников/документов. Текущие 8 записей в реестре — только кандидаты, все со статусом UNKNOWN/pending; автоматического допуска нет.
- В первой версии — публичные материалы, минимальный интерфейс «вопрос → ответ → источники», без административной панели, учётных записей, CRM, multi-tenant, загрузки файлов пользователями и автономных действий.
- Облачная генерация допустима только для источников, у которых отдельно утверждены cloud_generate и cloud_allowed. Возможность перейти на локальную модель должна сохраняться.
